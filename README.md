# Grafit — Laravel Upgrade Project

## Project Overview

This project is a legacy Laravel application upgrade from Laravel 5.6 to Laravel 10, including frontend modernization and deployment improvements.

## What was done

- Upgraded Laravel 5.6 → Laravel 10
- Migrated Bootstrap 3 → Bootstrap 5.3
- Integrated Vite build system
- Configured IIS deployment for Laravel application on Windows Server
- Improved frontend responsiveness
- Removed legacy Vue.js (not used)

## Technologies

- Laravel 10
- PHP 8+
- Bootstrap 5.3
- Vite
- Axios
- IIS (Windows Server)
- Node.js
